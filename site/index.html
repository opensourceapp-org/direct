Direct

Run the server yourself.

Clone the repository, install the desktop app, and start a server on your computer. The app shows an address you can share. Each phone that saves that address appears in the app. The server only introduces the phones. It does not store messages.

Clone DIRECT

The project lives at github.com/opensourceapp-org/direct.

git clone https://github.com/opensourceapp-org/direct.git
cd direct
pnpm install
pnpm server

You need Node.js 22 or newer and pnpm. pnpm server downloads the desktop app the first time, then opens the Direct server window. Leave that terminal open while the window is in use.

On a Mac, double-click Start Server.command in the project folder. That runs the same steps. Direct.app is the iPhone app. macOS will not open it, and shows “this application is not supported on this Mac.” Run the iPhone app from Xcode on an iPhone.

Start it and share the address

In the window, press Start server. Copy a ws:// address, for example ws://192.168.1.20:8787. On both phones, open Network and save that same address. Allow TCP port 8787 through the computer’s firewall.

Check it in a browser: http://192.168.1.20:8787/health answers {"ok":true,"service":"direct-signaling","contract":1}.

Who is connected

When a phone connects, its name and DIRECT ID appear under Connected phones. That list stays on this computer. Other phones cannot download it.

Without the window

The same server can run in a terminal with pnpm signaling. It prints the addresses to share. Closing the terminal or the window stops the server.
